# Tic Tac Toe 🎮

A modern and interactive Tic Tac Toe game built using React and Tailwind CSS with smooth animations, winner detection, and beautiful glassmorphism UI.

---

## ✨ Features

* Modern and responsive UI
* Interactive gameplay
* Real-time player turn indicator
* Winner detection
* Draw detection
* Animated popup on match end
* Restart game functionality
* Smooth hover and transition effects
* Glassmorphism + neon styled design

---

## 🎯 Game Rules

* Two players take turns playing as **X** and **O**
* First player to align 3 symbols:

  * Horizontally
  * Vertically
  * Diagonally
    wins the match
* If all cells are filled and no player wins, the match ends in a draw
